# Conversão de Pixel Art para Receitas de Crochê

Projeto desenvolvido como Trabalho de Conclusão de Curso em Análise e Desenvolvimento de Sistemas.

Objetivo:
Converter imagens pixeladas em instruções textuais para confecção manual em crochê utilizando processamento digital de imagens.

Tecnologias

- Python
- OpenCV
- NumPy
- Scikit-Learn
